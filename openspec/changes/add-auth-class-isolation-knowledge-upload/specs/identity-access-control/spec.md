## Purpose

为课程系统提供可验证的账号密码登录、会话保护和教师/学生角色授权，并通过预置演示数据、密码哈希和服务端环境变量满足基础安全验收。

## ADDED Requirements

### Requirement: 教师和学生可使用账号密码登录
系统 SHALL 允许已启用的教师账号和学生账号使用用户名与密码登录。凭据验证成功后，系统 SHALL 建立可由服务端验证的会话；验证失败时 MUST NOT 建立会话。

#### Scenario: 教师登录成功
- **WHEN** 预置教师提交正确的用户名和密码
- **THEN** 系统建立教师会话并将用户带到受保护页面

#### Scenario: 学生登录成功
- **WHEN** 预置学生提交正确的用户名和密码
- **THEN** 系统建立学生会话并将用户带到受保护页面

#### Scenario: 密码错误
- **WHEN** 用户提交存在的用户名和错误密码
- **THEN** 系统返回登录失败结果且不建立认证会话

#### Scenario: 用户不存在
- **WHEN** 用户提交不存在的用户名
- **THEN** 系统返回与错误密码一致的通用失败结果且不泄露账号是否存在

### Requirement: 受保护页面和 API 必须验证会话
系统 SHALL 在服务端验证每个受保护请求的会话。未登录浏览器访问受保护页面时 SHALL 被引导到登录页；未登录客户端调用受保护 API 时 SHALL 返回 HTTP 401。

#### Scenario: 未登录访问受保护页面
- **WHEN** 未认证用户访问材料列表或上传页面
- **THEN** 系统跳转到登录页，并可在登录成功后返回安全的原目标页面

#### Scenario: 未登录调用受保护 API
- **WHEN** 未认证客户端调用材料列表或上传 API
- **THEN** 系统返回 HTTP 401 且不执行查询、文件保存或数据库写入

#### Scenario: 退出后再次访问
- **WHEN** 用户退出登录后再次访问受保护资源
- **THEN** 原会话不再有效，页面访问被引导到登录页或 API 返回 HTTP 401

### Requirement: 服务端按可信角色执行授权
系统 SHALL 从数据库中的用户记录加载 `teacher` 或 `student` 角色，并 SHALL 在服务端判断教师专属操作。客户端提交的角色、用户 ID 或表单字段 MUST NOT 提升权限。

#### Scenario: 教师进入上传流程
- **WHEN** 已认证教师访问上传页面或调用上传 API
- **THEN** 系统通过角色检查并继续执行班级权限检查

#### Scenario: 学生伪造教师角色
- **WHEN** 已认证学生在表单、请求体或请求头中伪造教师角色
- **THEN** 系统仍按数据库中的学生角色处理并拒绝教师专属操作

### Requirement: 密码必须以安全哈希存储
系统 SHALL 使用带盐的专用密码哈希函数生成和校验密码，数据库 MUST 只保存密码哈希。系统 MUST NOT 在数据库、日志、配置文件或响应中保存或输出明文密码。

#### Scenario: 初始化预置账号
- **WHEN** 初始化命令创建教师或学生账号
- **THEN** 数据库保存不可直接还原的密码哈希，且该字段不等于初始化密码

#### Scenario: 登录校验密码
- **WHEN** 用户提交登录密码
- **THEN** 系统使用密码哈希校验函数比较密码且不记录明文值

#### Scenario: 检查持久化数据
- **WHEN** 验收者查看用户表和应用日志
- **THEN** 其中不存在预置账号或登录请求的明文密码

### Requirement: 提供可重复执行的预置演示数据
系统 SHALL 提供幂等的初始化命令，至少创建 A 班、B 班、一名 A 班教师、一名 A 班学生和一名 B 班学生。初始化密码 SHALL 从服务端环境变量或初始化命令参数读取并在写入前哈希。

#### Scenario: 首次初始化
- **WHEN** 操作者在空数据库执行预置数据初始化命令并提供初始化密码
- **THEN** 系统创建两个班级、教师和学生账号及正确的班级成员关系

#### Scenario: 重复初始化
- **WHEN** 操作者对已初始化数据库再次执行同一命令
- **THEN** 系统不创建重复用户、班级或成员关系，并保持账号可登录

#### Scenario: 使用预置数据验证跨班边界
- **WHEN** 验收者分别使用 A 班和 B 班预置账号登录
- **THEN** 两组账号具有不同的服务端班级关系，可用于验证跨班访问被拒绝

### Requirement: 密钥仅从服务端环境变量读取
系统 SHALL 从服务端环境变量读取 Flask 会话密钥及其他敏感配置，MUST NOT 将真实密钥提交到源码、镜像、浏览器代码或 API 响应中。缺少必需密钥时，应用 MUST NOT 进入健康状态。

#### Scenario: 会话密钥已配置
- **WHEN** 应用在设置必需服务端环境变量后启动
- **THEN** 系统使用该密钥保护会话且不向客户端返回密钥值

#### Scenario: 会话密钥缺失
- **WHEN** 应用在缺少必需会话密钥时启动
- **THEN** 应用启动失败或 `GET /health` 返回非 2xx，诊断信息不包含任何密钥值
